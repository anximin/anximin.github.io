如何彻底删除打印机

方法一：通过“设置”应用程序删除

  1. 按下Win+I组合键打开“设置”应用程序。

  2. 在左侧窗格中选择“蓝牙和设备”，然后在右侧点击“打印机和扫描仪”。

  3. 在列表中单击要删除的打印机，然后选择“删除”。

  4. 系统会提示确认删除，点击“是”完成操作。

方法二：通过设备管理器卸载驱动程序

  1. 右键单击“开始”菜单，选择“设备管理器”。

  2. 在设备管理器中，展开“打印队列”分支。

  3. 右键单击目标打印机，选择“卸载设备”。

  4. 系统会提示确认卸载，点击“卸载”完成

方法三：使用打印管理删除驱动程序包

  1. 按Win+R打开运行窗口，输入“printmanagement.msc”并按Enter打开“打印管理”。

  2. 在左侧窗格中选择“所有驱动程序”（在自定义过滤器下）。

  3. 找到并右键单击要删除驱动程序的打印机，选择“删除驱动程序包”。

  4. 系统会提示确认删除，点击“是”完成操作。

方法四：通过命令提示符或PowerShell删除

    对于高级用户，可以使用命令提示符或PowerShell来删除打印机驱动程序。

    例如，通过PowerShell，可以使用“Get-PrinterDriver”命令列出所有打印机驱动程序，

    然后使用“Remove-PrinterDriver -Name ‘Printer Name’”命令删除指定的驱动程序。

方法五：手动删除打印机后台文件

  1. 按Win+R打开运行窗口，输入“spool”并按Enter。

  2. 在“C:\Windows\System32\spool\PRINTERS”文件夹中删除所有文件。

  3. 返回“设备和打印机”窗口，删除打印机并刷新，确保打印机不再重新出现。
