群晖修改Docker的bridge网络默认局域网地址

群晖7.2.2管理Docker使用的是Container Manager，修改bridge网络的默认局域网地址。

1. 打开SSH

 控制面板 -> 终端机和SNMP -> 勾选 启动SSH功能

2. 使用终端通过SSH登录群晖，并sudo -i 切换为root模式

root@SA6400:/var# ps aux | grep dockerd
root     24594  0.0  0.1 2912336 59960 ?       Ssl  17:10   0:00 /var/packages/ContainerManager/target/usr/bin/dockerd --config-file /var/packages/ContainerManager/etc/dockerd.json
root     30158  0.0  0.0  33220  2440 pts/0    S+   17:27   0:00 grep --color=auto dockerd

通过输出的结果可以看到 “/var/packages/ContainerManager/etc/dockerd.json”这个文件控制着docker的配置。

3. 使用vi编辑这个文件

{"bip":"192.168.16.1/24","data-root":"/var/packages/ContainerManager/var/docker","default-address-pools":[{"base":"192.168.16.0/24","size":24}],"log-driver":"db","registry-mirrors":["https://dockerhub.azk8s.cn","https://hub-mirror.c.163.com","https://mirror.ccs.tencentyun.com","https://docker.m.daocloud.io","https://docker.jianmuhub.com","https://huecker.io","https://dockerhub.timeweb.cloud","https://dockerhub1.beget.com","https://noohub.ru"],"seccomp-profile":"unconfined","storage-driver":"btrfs"}

重点是添加”bip”:”192.168.16.1/24” 和 “default-address-pools”:[{“base”:”192.168.16.0/24”,”size”:24}]要注意JSON格式。

其中的IP地址是自定义的子网地址。

4. 保存该文件并重启ContainerManager
